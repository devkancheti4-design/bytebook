Move from C to C++ and master object-oriented design: classes, constructors, inheritance, polymorphism, templates, exceptions and the STL.

What you will be able to do

  • Explain the four pillars of OOP with real code
  • Design classes with constructors, destructors and access control
  • Use inheritance, virtual functions and abstract classes
  • Overload functions and operators
  • Write generic code with templates
  • Use STL containers and algorithms productively

Syllabus

Unit 1From C to C++

  1. 1C++ IntroductionWhere C++ came from, what it adds to C, your first program with iostream and namespaces, and how to compile it.3 min
  2. 2Input/Output, Strings & ReferencesRead and write with cin and cout, use the std::string class, format output with iomanip, and meet references — C++'s safer alias for a variable.4 min
  3. 3Functions: Overloading, Defaults & InlineWhat C++ adds to functions: pass by reference, const references, function overloading, default arguments and inline functions.4 min

Unit 2Classes & Objects

  1. 4OOP ConceptsWhy object-oriented programming exists, the difference from procedural code, and the four pillars — encapsulation, abstraction, inheritance and polymorphism.4 min
  2. 5Classes & ObjectsDefine a class with data members and member functions, create objects, control access with public and private, and define methods outside the class with ::.4 min
  3. 6Constructors & DestructorsInitialise objects automatically: default, parameterised and copy constructors, initialiser lists, constructor overloading, and destructors with the order they run in.5 min
  4. 7Encapsulation, this & static MembersGetters and setters with validation, the this pointer, const member functions, and static data and functions shared by every object.4 min
  5. 8Friend Functions & ClassesGrant selected functions or classes access to private members — when it is useful, how it works, and why to use it sparingly.3 min

Unit 3Inheritance & Polymorphism

  1. 9InheritanceReuse and extend classes: base and derived classes, public/protected/private inheritance, the five types of inheritance, constructor order, and the diamond problem.6 min
  2. 10Operator OverloadingMake your own types work with +, ==, <<, [] and more: member vs friend operators, unary and binary operators, and the rules you must follow.5 min
  3. 11Virtual Functions & Runtime PolymorphismBase-class pointers to derived objects, why virtual changes which function runs, override, virtual destructors, and how the vtable makes it work.5 min
  4. 12Abstract Classes & InterfacesPure virtual functions, abstract base classes that cannot be instantiated, interfaces, and the final keyword — designing a clean class hierarchy.4 min

Unit 4Beyond the Basics

  1. 13TemplatesWrite code once for any type: function templates, class templates, multiple type parameters, non-type parameters and specialisation — the foundation of the STL.4 min
  2. 14Exception HandlingHandle errors cleanly with try, throw and catch: standard exception classes, multiple and catch-all handlers, custom exceptions, and stack unwinding.5 min
  3. 15Dynamic Memory & Smart Pointersnew and delete, arrays on the heap, shallow vs deep copy, the rule of three, and modern smart pointers — unique_ptr and shared_ptr — that free memory for you.5 min
  4. 16STL ContainersThe Standard Template Library's ready-made data structures: vector, list, deque, stack, queue, priority_queue, set, map and their unordered versions — with costs.4 min
  5. 17Iterators, Algorithms & LambdasWalk any container with iterators, then use the STL algorithms — sort, find, count, binary_search, accumulate, transform — with lambda functions for custom behaviour.4 min
  6. 18File I/O with fstreamRead and write files the C++ way with ifstream, ofstream and fstream: modes, line-by-line reading, parsing records with stringstream, and binary files.3 min
  7. 19C++ OOP Cheat Sheet & Exam PrepThe whole OOPS course on one page: syntax for classes, constructors, inheritance and polymorphism, the comparisons examiners love, and programs to practise.3 min
