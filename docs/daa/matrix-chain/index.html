Dynamic Programming

Matrix Chain Multiplication

Find the cheapest way to parenthesise a product of matrices: why order matters, the m[i][j] recurrence, filling the table by chain length, and printing the optimal parenthesisation.

3 min read1 runnable example4-question quiz

Multiplying a p × q matrix by a q × r matrix takes p·q·r scalar multiplications. Matrix multiplication is associative — (AB)C = A(BC) — but the cost depends on the order.

Example: A is 10 × 100, B is 100 × 5, C is 5 × 50.

Order Cost
(AB)C 10·100·5 + 10·5·50 = 5,000 + 2,500 = 7,500
A(BC) 100·5·50 + 10·100·50 = 25,000 + 50,000 = 75,000

Ten times difference for three matrices. For a chain of n matrices, the number of parenthesisations grows exponentially (the Catalan numbers), so we use DP.

#Recurrence

Matrix Aᵢ has dimensions p[i−1] × p[i]. State: m[i][j] = minimum cost to multiply Aᵢ … Aⱼ.

m[i][i] = 0 m[i][j] = min over i ≤ k < j of ( m[i][k] + m[k+1][j] + p[i−1]·p[k]·p[j] )

Split the chain after Aₖ: multiply the left part, the right part, then the two results. Store the best k in s[i][j] to rebuild the parenthesisation.

Fill order: by increasing chain length L = 2, 3, …, n (each cell needs shorter chains).

This is the classic CLRS example: the answer is 15,125 with ((A1(A2A3))((A4A5)A6)).

Time O(n³) (n² cells, each trying up to n splits), space O(n²).

How to present it

Draw the m table (upper triangle) and the s table. Fill them diagonal by diagonal, showing the k computation for at least one cell, e.g. m[2][5] = min over k = 2, 3, 4, then print the parenthesisation from s.

Test yourself

4 questions · pick an answer to check it instantly

  1. 1

    What is the cost of multiplying a 4 × 6 matrix by a 6 × 3 matrix?

    p·q·r = 4 × 6 × 3 = 72.
  2. 2

    In what order is the m table filled?

    Each cell depends on cells for shorter chains.
  3. 3

    What is the time complexity of the matrix-chain DP?

    O(n²) subproblems, each examining O(n) split points.
  4. 4

    What does s[i][j] store?

    It is used to print the optimal parenthesisation.
