Dynamic Programming

0/1 Knapsack

Choose whole items to maximise value within a weight limit: the DP table, the recurrence, tracing back the chosen items, and a space-optimised version.

4 min read2 runnable examplesInteractive4-question quiz

You have n items, each with a weight and a value, and a knapsack of capacity W. Each item is taken whole or not at all (0 or 1). Maximise the total value without exceeding W.

Greedy by value-per-weight fails here (see the greedy lesson); trying all 2ⁿ subsets is too slow. DP solves it in O(nW).

#State and recurrence

State: dp[i][w] = the best value achievable using the first i items with capacity w.

For item i (weight wᵢ, value vᵢ), either skip it or take it (if it fits):

dp[i][w] = dp[i−1][w] if wᵢ > w dp[i][w] = max(dp[i−1][w], vᵢ + dp[i−1][w − wᵢ]) otherwise

Base: dp[0][w] = 0 (no items) and dp[i][0] = 0 (no capacity). Answer: dp[n][W].

Traceback: start at dp[n][W]. If the value equals the cell above, item i was skipped; otherwise it was taken — subtract its weight and move up.

#Space optimisation

Each row depends only on the previous row, so one 1-D array suffices if you loop w downwards (so each item is used at most once):

Looping w upwards would allow an item to be reused — which solves the unbounded knapsack instead.

Pseudo-polynomial time

O(nW) looks polynomial, but W is a number, not the input's length: it takes only log W bits to write down. If W is huge (say 10¹⁸), the table is impossible. 0/1 knapsack is in fact NP-hard — see NP-Completeness.

    In 0/1 knapsack, what does dp[i][w] represent?

    Defining the state in words is the first step of any DP.
  2. 2

    If wt[i] > w, what is dp[i][w]?

    Item i cannot fit, so the answer is the same as without it.
  3. 3

    Items (w, v): (1, 1), (3, 4), (4, 5), (5, 7); W = 7. What is the maximum value?

    Taking the items of weight 3 and 4 gives value 4 + 5 = 9.
  4. 4

    In the 1-D version, why loop w from W down to wt[i]?

    Going downwards reads values from the previous item's row before they are overwritten.
