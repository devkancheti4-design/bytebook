Programming in C

Start from zero and learn to think like a programmer in C: variables, decisions, loops, functions, arrays, strings, pointers, memory, structures and files.

What you will be able to do

  • Write, compile and run complete C programs
  • Use if, switch and loops to solve pattern and number problems
  • Break programs into functions and solve problems recursively
  • Work with arrays, strings and 2D matrices
  • Understand pointers, addresses and dynamic memory
  • Model data with structures and save it to files

Syllabus

Unit 1Getting Started

  1. 1C IntroductionWhat C is, why it still runs the world, and your very first program — explained line by line.4 min
  2. 2Syntax, Output & CommentsThe grammar rules of C, how printf prints text and numbers, escape sequences, and how to comment code.3 min
  3. 3Variables, Data Types & ConstantsStore values in variables, choose the right data type, print them with the right format specifier, and lock values with constants.4 min
  4. 4User Input with scanfRead numbers, characters and whole lines from the keyboard — and avoid the three classic scanf traps.4 min
  5. 5Operators & ExpressionsArithmetic, increment, relational, logical, bitwise and ternary operators — plus precedence and type casting, which examiners love.7 min

Unit 2Control Flow

  1. 6If, Else & SwitchMake decisions with if, else if, nested conditions and switch — with the classic grade, leap-year and calculator programs.4 min
  2. 7Loops: while, do-while and forRepeat work with the three C loops, choose the right one, and write the classic digit, factorial, prime and Fibonacci programs.5 min
  3. 8Break, Continue & Pattern ProgramsControl loops with break, continue and goto, then master nested loops through the star and number patterns every exam asks for.5 min

Unit 3Functions

  1. 9FunctionsSplit programs into named, reusable pieces: declarations, definitions, parameters, return values and call by value.5 min
  2. 10RecursionFunctions that call themselves: base cases, the call stack, and the factorial, Fibonacci, power, digit-sum and Tower of Hanoi programs.5 min
  3. 11Scope & Storage ClassesWhere variables live and how long they last: local, global and block scope, plus the auto, static, extern and register storage classes.3 min

Unit 4Arrays & Strings

  1. 12ArraysStore many values of one type under one name: declaring, indexing, looping, and the sum, max, search and reverse programs.5 min
  2. 132D Arrays & MatricesRows and columns: declaring 2D arrays, reading matrices, and the addition, transpose, multiplication and diagonal-sum programs.4 min
  3. 14StringsCharacter arrays ending in '\0': reading strings, the string.h functions, and writing length, reverse, palindrome and vowel-count programs yourself.4 min

Unit 5Pointers & Memory

  1. 15PointersAddresses, the & and * operators, pointer types, NULL, and pointer arithmetic — the idea that makes C powerful.5 min
  2. 16Pointers, Arrays & FunctionsCall by reference, the swap function, returning several results, how arrays decay to pointers, and pointers to strings.6 min
  3. 17Dynamic Memory AllocationAsk for memory at run time with malloc, calloc and realloc, give it back with free, and avoid leaks and dangling pointers.5 min

Unit 6Structures, Files & More

  1. 18Structures, Unions & EnumsGroup related data with struct, name types with typedef, use arrays of structures and pointers to them, and compare structures with unions and enums.5 min
  2. 19File HandlingSave data that outlives your program: open, write, read, append and close text files with fopen, fprintf, fscanf, fgets and friends.4 min
  3. 20Preprocessor, Macros & Command-Line ArgumentsWhat happens before compilation: #include, #define macros and their traps, conditional compilation, header guards, and reading arguments with argc/argv.4 min
  4. 21C Cheat Sheet & Exam PrepEverything from CSE 101 on one page: syntax, format specifiers, operators, must-know programs and the mistakes that cost marks.4 min
