Preprocessor, Macros & Command-Line Arguments

What happens before compilation: #include, #define macros and their traps, conditional compilation, header guards, and reading arguments with argc/argv.

4 min read4 runnable examples4-question quiz

Before the compiler sees your code, the preprocessor runs. It handles every line starting with #. It does pure text substitution — it does not understand C types or syntax.

No type checking Arguments are type-checked

#Command-line arguments

main can receive the words typed after the program name:

  • argc — argument count, including the program name.
  • argv — argument vector: an array of strings. argv[0] is the program name.

Test yourself

4 questions · pick an answer to check it instantly

  1. 1

    What does #define TRIPLE(x) x * 3 give for TRIPLE(2 + 1)?

    Text substitution gives 2 + 1 * 3 = 2 + 3 = 5. Bracket macro parameters: ((x) * 3).
  2. 2

    What is argv[0]?

    User arguments start at argv[1]; argc counts all of them including the program name.
  3. 3

    What are header guards for?

    #ifndef X / #define X / ... / #endif makes repeated includes harmless.
  4. 4

    When do preprocessor directives run?

    The preprocessor rewrites the source text before the compiler proper starts.
